
# Python Rotating 3D Cube

## Description
This project is a simple 3D wireframe cube created using Python, Pygame, and PyOpenGL. The cube rotates continuously, demonstrating basic 3D computer graphics and animation.

## Features
- Displays a 3D wireframe cube.
- Rotates the cube continuously.
- Uses OpenGL for 3D rendering.
- Uses Pygame to create the display window and handle events.
- Organized using a Python main function.

## Technologies Used
- Python
- Pygame
- PyOpenGL
- OpenGL and GLU

## Requirements
- Python 3
- Pygame
- PyOpenGL

## Installation

Install the required libraries using pip:

```bash
python -m pip install -r requirements.txt
```

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python rotating_cube.py
```

A window will open displaying the rotating 3D cube. Close the window to exit the program.
